# Email Verification API

API simples para envio de emails de verificação com template HTML, desenvolvida para fins de teste.

## Descrição

Esta API permite o envio automatizado de emails de verificação com códigos de segurança. Ideal para sistemas que necessitam de confirmação por email, recuperação de senha ou autenticação em duas etapas.

## Funcionalidades

- Envio de emails de verificação com códigos
- Template HTML moderno e responsivo
- Configuração simples com Gmail SMTP
- Validação de campos obrigatórios
- Respostas padronizadas em JSON
